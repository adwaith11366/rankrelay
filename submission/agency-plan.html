RankRelay agency plan

An 8-agent SEO and AEO agency built on the ai-employees kits

Agency type

RankRelay is an SEO and AEO agency. It improves how a site performs in search and how likely AI answer engines are to cite it. Its demo client is Shoestring Atlas, a fictional budget travel blog on GitHub Pages with 10 planted defects, so the audit has known answers to check against.

How a day runs

At 7:15 AM a crawler reads the live site. Four agents analyse it in parallel, the writer drafts, then the campaign and outbound agents build on the draft. Code checks every output before the Project Manager reviews the work.

Reporting

Each run adds a row per agent to the ledger: Timestamp, Agent Name, Task Performed, Output Status. An Apps Script trigger emails the bulletin at 8:00 AM, and warns if no agent ran in the last 24 hours.

Latest result

8 of 8 agents finished in 3m 26s. The crawl checked 9 URLs and scored the site SEO 85 and AEO 41 out of 100.

Guardrails

Agents write only to their run folder. Replies, outreach and ads stay as drafts until a person approves them.
