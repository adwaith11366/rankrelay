# Seeded defects in the demo site

Shoestring Atlas is fictional. These defects were put in on purpose so the audit has known answers to check against.

1. `hostel-vs-guesthouse.html` has no meta description.
2. `hostel-vs-guesthouse.html` has an image with no alt text.
3. `eat-on-a-budget.html` has no H1.
4. `eat-on-a-budget.html` is live but missing from `sitemap.xml`.
5. `cheap-flights-timing.html` links to `travel-insurance-basics.html`, which doesn't exist (404).
6. `packing-list-backpack.html` is an orphan page: no internal link points to it, and it isn't in the sitemap.
7. `packing-list-backpack.html` duplicates the title and description of `how-to-pack-carry-on-only.html`.
8. `visa-free-basics.html` is thin (one sentence) with a weak title and description.
9. Only one page has JSON-LD schema, and none has FAQPage schema.
10. The site has no `llms.txt`.
